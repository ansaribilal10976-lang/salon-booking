# Local fonts

The landing identity uses two families: **Bodoni Moda** for display typography and the existing **Geist Sans** for body/UI text. Both are loaded with `next/font/local`; there is no runtime Google Fonts request.

- `BodoniModa-Regular.ttf`: unmodified regular 400 font, downloaded from the Google Fonts CSS response for Bodoni Moda on this redesign.
  - Font: https://fonts.gstatic.com/s/bodonimoda/v28/aFT67PxzY382XsXX63LUYL6GYFcan6NJrKp-VPjfJMShrpsGFUt8oU7awIA.ttf
  - Upstream project: https://github.com/indestructible-type/Bodoni
  - License: SIL Open Font License 1.1, included in `BodoniModa-OFL.txt` from https://raw.githubusercontent.com/google/fonts/main/ofl/bodonimoda/OFL.txt
- `GeistVF.woff`: existing repository asset; unchanged.
- `GeistMonoVF.woff`: existing repository asset; unchanged. Used for operational reference IDs, not the landing identity; not preloaded.

Replace these choices if the salon supplies an approved type system. Preserve font licenses when redistributing assets.
